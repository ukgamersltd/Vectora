# Vectora — Vector Design Studio

An independent Illustrator-inspired vector editor built with plain HTML, CSS, JavaScript, and WGSL.

The source includes a WebGPU rendering backend with a Canvas 2D compatibility fallback, editable vector paths and shapes, text editing, SVG import/export, native document persistence, and automated tests.

This repository is being initialized with the Vectora 0.1 source and a GitHub Pages deployment workflow.

Vectora is not affiliated with Adobe.
