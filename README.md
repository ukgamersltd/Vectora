## 🖌️ How to Use Vectora - A Quick Tour

Once Vectora opens in your browser, you will see a clean interface designed for productivity. Here is a simple breakdown of the main areas:

### The Canvas Area (Center)
This is where your artwork lives. You will see three artboards in the example document, each acting like a separate page or canvas. You can select objects on these artboards, move them around, resize them, and edit their shapes\.

###The Toolbar (Left Side or Top)
Here you will find all the drawing tools mentioned earlier: 
- **Selection Tool (V)**: Click to select objects, drag to move them, use corner handles to resize or rotate\.

- **Pen Tool (P)**: Click to place anchor points, drag to create curves, and connect points to draw custom paths\.

- **Shape Tools**: Rectangle, Rounded Rectangle, Ellipse, Polygon, Star, Line - just click and drag on canvas to create these shapes instantly\.


- **Pencil & Brush Tools**: Freehand drawing for sketchy lines or smooth brush strokes\.


###The Properties Panel (Right Side)
When you select an object, this panel shows its properties - fill color, stroke color, stroke width, opacity, position, size, rotation, and more\. You can change any of these values numerically or with color pickers for precise control\mathbb.


###The Layers Panel (Right Side or Bottom)
Think of layers like transparent sheets stacked on top of each other\. You can create new layers, reorder them, show or hide them, lock them, and organize your drawing structure\. This is essential for complex artwork\.


###The Top Menu (Top Bar)
Contains standard options like File (New, Open, Save\), Edit (Undo, Redo, Copy, Paste\), Object (Group, Ungroup, Align, Distribute\), and Help\.

### Troubleshooting Common Issues

**Problem**: Double-clicking `index.html` opens a blank page\. 
**Solution**: Make sure you extracted **all** files from the zip archive into the same folder\. The HTML file needs its associated JavaScript and CSS files to work\. Do not move only the HTML file alone to another location\.

**Problem**: The browser shows a warning about "WebGL" or "WGSL" not being supported\. 
**Solution**: WGSL is used for hardware-accelerated rendering\. Update your browser to the latest version, or enable hardware acceleration in your browser's settings\. Older browsers or those runningin compatibility modes may not support this technology\.

**Problem**: The interface looks misaligned or broken\. 
**Solution**: Ensure your browser zoom level is set to 100% (Ctrl+0 on Windows\). Vectora is designed for standard modern screen resolutions\.

**Problem**: Cannot find the download link on GitHub. 
**Solution**: Look for a section labeled "Releases" on the right side of the repository page, or click on the "Tags" tab. The latest release will have a downloadable zip file attached. Alternatively, you can click the green "Code" button and select "Download ZIP" to get the latest development version - though the releases version is recommended for stability\.


## 🎓 Tips for Getting the Most Out of Vectora

1. **Start with the Example Document**: When you first open Vectora, explore the 38 objects across three artboards\. Try selecting, moving, and editing them to understand how the tools behave\.

2. **Learn Keyboard Shortcuts**: Like all professional editors, Vectora supports shortcuts like V for Selection, P for Pen, Ctrl+Z for Undo, Ctrl+C/V for Copy/Paste\. These will speed up your workflow dramatically\.

3. **Use Guides and Snapping**: Turn on snapping from the View menu to make aligning objects perfectly easy\. Drag guides out from the rulers (if visible\) to create precise reference lines\.

4. **Practice with Layers**: The earlier you adopt a layer-based workflow, the easier complex projects become\. Keep different elements (background, foreground, details\) on separate layers\.

5. **Save Your Work**: Use `File > Save` to download your document as a JSON file\. You can later open this file using `File > Open` to continue working\. This is crucial for not losing your progress\.
